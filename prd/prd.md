# **Project Requirements Document: Orange Concrete Services Web App**

The following table outlines the detailed functional requirements of the Orange Concrete Services web application MVP.

| Requirement ID | Description                 | User Story                                                                                                                                      | Expected Behavior/Outcome                                                                                                                                                            |
| -------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| FR001          | Immersive Landing Page      | As a user, I want to be greeted with high-quality visuals of concrete projects so I can immediately understand the quality of services offered. | The system should display a fullscreen background video or high-resolution images of concrete projects with parallax scrolling effects.                                              |
| FR002          | Service Catalog             | As a user, I want to browse different concrete services offered so I can determine if they meet my needs.                                       | The system should provide a visually appealing catalog of services with industrial-inspired UI elements, showcasing different concrete options with descriptions and example images. |
| FR003          | Interactive Project Gallery | As a user, I want to view completed projects so I can assess the quality and style of work.                                                     | The system should display a grid-based gallery of projects with before/after sliders and the ability to filter by project type or location within Orange and surrounding areas.      |
| FR004          | Basic 3D Models             | As a user, I want to interact with 3D models of concrete designs to better visualize potential outcomes.                                        | The system should provide at least 3 interactive 3D models of common concrete elements (e.g., countertops, driveways, stamped concrete) that users can rotate and zoom.              |
| FR005          | Quote Request Form          | As a user, I want to submit project details to receive an estimate so I can plan my budget.                                                     | The system should provide an interactive form with micro-animations that guides users through inputting project specifications and location within the service area.                 |
| FR007          | Mobile Responsiveness       | As a user, I want to access the website on my mobile device so I can browse services on the go.                                                 | The system should provide a seamless mobile experience with appropriately sized elements and touch-friendly navigation.                                                              |
| FR008          | Dark/Light Mode Toggle      | As a user, I want to switch between dark and light modes so I can view the site comfortably in different lighting conditions.                   | The system should provide a toggle switch that changes the UI between industrial dark mode with high-contrast accents and a lighter alternative.                                     |
| FR009          | Contact Information         | As a user, I want to easily find contact information so I can reach out with questions.                                                         | The system should display prominent contact details with micro-interactions for phone number clicking or email copying.                                                              |
| FR010          | Basic Chatbot Support       | As a user, I want instant answers to common questions so I don't have to wait for a response.                                                   | The system should provide a simple AI chatbot that can answer FAQs about concrete services, pricing factors, and project timelines.                                                  |
| FR014          | Testimonials Showcase       | As a user, I want to read what other customers say about the services so I can trust the quality.                                               | The system should display a rotating carousel of client testimonials with project photos from locations throughout Orange and surrounding areas.                                     |
| FR015          | Basic Concrete Calculator   | As a user, I want to estimate the amount of concrete needed for my project so I can have a general idea of scope.                               | The system should provide a simple calculator that converts dimensions to required concrete volume with visual feedback.                                                             |
